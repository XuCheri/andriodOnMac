# 安装与连接

## Mac 安装

需要 Apple Silicon（M1 或更新）及 macOS 13+。从本项目 GitHub Release 下载 DMG，打开后将 AndroidOnMac 拖到“应用程序”。ZIP 版本解压后同样移动到“应用程序”。无需安装 Homebrew、ADB 或 scrcpy。

当前预览包使用 ad-hoc 签名，**没有 Developer ID 签名或 Apple 公证**。首次打开时系统可能拦截：确认下载来源与 Release 的 SHA-256 后，先尝试打开一次，再到“系统设置 → 隐私与安全性”，找到 AndroidOnMac 的提示，按“仍要打开”并确认。仅在你确认这是自己信任的发行包时操作。

不要关闭 Gatekeeper、关闭系统保护或执行批量移除隔离属性的命令。企业设备若被管理员策略禁止，按组织流程处理。系统若明确报告恶意软件、文件损坏或签名与发布记录不符，不应将其当作普通未公证提示绕过。

macOS 若询问“本地网络”权限，允许 AndroidOnMac 访问后才能发现和连接局域网手机。

## 首次 USB 连接

1. 用支持数据传输的 USB 线连接 Mac 与手机；仅充电线无法使用。
2. 在手机“关于手机”连续点击版本号开启开发者选项，按系统指引启用“USB 调试”。
3. 解锁手机，确认“允许 USB 调试”提示。只有你自己的可信 Mac 才勾选“始终允许”。
4. 在 AndroidOnMac 刷新设备列表，选择已授权手机，开始镜像。

`unauthorized` 表示需要在手机上授权；`offline` 表示连接暂时不可用。先检查手机解锁状态、数据线和 USB 模式。部分小米/MIUI/HyperOS 机型还需要开发者选项里的“USB 调试（安全设置）”，其要求以手机实际提示为准。

## Android 11+ 无线连接

Mac 与手机连接同一局域网，建议使用稳定的 5 GHz / 6 GHz Wi-Fi。在手机开发者选项中开启“无线调试”，然后点这一行的文字进入详情页；旁边的开关只负责开启。小米手机通常从“设置 → 更多设置 → 开发者选项”进入。

1. 点“使用配对码配对设备”，记录弹窗里的 IP、**配对端口**和 6 位配对码。
2. 在 AndroidOnMac 的无线配对界面填写这组配对信息，保持手机配对弹窗可见直到成功。
3. 回到手机“无线调试”的主页面，读取 IP 与**连接端口**，使用该地址连接。连接端口通常与配对端口不同，网络切换后也可能变化。
4. 设备出现在列表并显示就绪后，开始镜像。

如果应用“自动发现”列出了这台手机，可点“填入配对地址”或“填入连接地址”自动填写。VPN / 虚拟网卡可能让手机显示其他接口地址；应使用 Mac 能访问的局域网地址。配对弹窗重新打开后，配对码与端口可能改变，请以当前信息为准。

“配对成功”不代表镜像已经建立；“ADB 已连接”也不代表视频或音频已经开始。公司/访客 Wi-Fi 可能隔离设备或阻止 mDNS，需换到允许设备互访的可信网络，或使用手动连接地址。

如果画面突然断开，先回手机确认“无线调试”开关仍开启。本次 Xiaomi / Android 16 实测出现过手机保持 Wi-Fi 在线、无线调试却自行关闭的情况，触发原因还未确认。此时 Mac 无法仅靠重试重新开启手机端服务；请手动重开开关，再从已保存设备连接。需要稳定使用时可先用 USB。不要为此关闭锁屏、修改安全保护或把调试端口暴露到公网。

Android 10 及更早系统没有这套配对码流程；需要先 USB 授权后启用旧式 TCP/IP 调试。首版界面主要面向 USB 与 Android 11+ 无线调试；旧式模式不自动开放手机端口。

## 输入、声音和使用习惯

- 在镜像窗口内点击是触摸，拖动是滑动，鼠标右键返回，常用快捷键以 [scrcpy 官方快捷键](https://github.com/Genymobile/scrcpy/blob/v5.0.1/doc/shortcuts.md) 为准。
- SDK 模式的文字注入限于 ASCII 和部分字符。中文建议先在 Mac 复制，再在镜像窗口粘贴；不要依赖“逐键输入文本”的旧式粘贴处理中文。
- UHID 模式把 Mac 键盘作为手机的实体键盘，首次需在 Android 配置实体键盘布局与输入法；它不直接搬运 Mac 输入法候选栏。旧 Android 可能不支持 UHID，可切回 SDK。
- 剪贴板同步会把内容送到另一端的系统剪贴板；可在会话选项中关闭。项目不会记录剪贴板正文或配对码。
- Android 12+ 音频通常直接工作；Android 11 开始时需解锁；Android 10 及以前没有音频转发。某些应用拒绝音频/画面捕获时，界面不能突破该限制。
- 网络抖动时先选流畅画质，优先用 USB 验证基线。更高分辨率和码率不一定更顺滑。

## 手机不在身边

本预览版只处理 USB / 同一局域网。Mac 与一台 ECS 并不能自动访问处于其他网络、没有预先授权链路的 Android 手机。跨网需要手机所在网络里保持在线的受控网关，或经手机用户批准的临时设备端组件，并另行设计身份授权、加密、连接撤销和断线恢复。

本项目当前没有部署 ECS 服务、开放公网 ADB 端口或配置隧道。请勿把手机调试端口直接暴露到公网。
