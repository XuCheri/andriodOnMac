# 安装 0.2.0-preview.1

Mac 需要 Apple Silicon 和 macOS 13+；接收 Mac 画面的 Android 端需要 Android 11+。从本项目 GitHub Release 下载 Mac DMG，将 AndroidOnMac 拖到“应用程序”；ZIP 版解压后同样移动。无需 Homebrew、ADB、scrcpy 或 Android Studio。

当前 Mac 预览包使用 ad-hoc 签名，尚未取得 Developer ID 签名或 Apple 公证。确认来源与 SHA-256 后，先尝试打开一次，再按“系统设置 → 隐私与安全性 → 仍要打开”的正常流程处理。不要关闭 Gatekeeper；明确的恶意软件或签名不符提示不能当作普通未公证提示绕过。

更新 ad-hoc 预览构建后，macOS 可能要求重新授予屏幕录制与辅助功能权限。若应用显示未授权而系统设置的开关已开启，可先关闭再开启该应用的开关，按系统提示重新启动，然后在应用内刷新授权状态。

## 安装 Android 接收端

只有“Mac → 手机”需要安装接收端；“手机 → Mac”保持原有免安装方式。

1. 用数据线连接 Android，开启 USB 调试并在手机授权这台 Mac。
2. 在 Mac 的“Mac → 手机”中刷新、选择手机，点击“安装接收端”。手机出现安装确认时按实际提示允许。
3. 安装后可通过 USB 开始投屏，也可拔线并使用同一 Wi-Fi 扫码连接。

也可在 Android 上下载 Release 中的 `AndroidOnMac-Receiver-0.2.0-preview.1.apk`，使用系统安装界面安装。若系统要求允许浏览器或文件管理器安装此来源的应用，核实来源后只为本次使用的安装来源授权。更新必须来自同一签名身份；签名冲突时不要直接清除数据或卸载来掩盖问题。

Mac → 手机需要 Mac 屏幕录制权限；触控和手机键盘输入另需辅助功能权限。Wi-Fi 连接可能需要 Mac 本地网络权限，手机扫码会请求相机权限；这条扫码连接不需要开启 Android 无线调试。音频默认关闭。

建议安装后先通过 USB 确认画面，再尝试副屏或 Wi-Fi。USB 镜像、独立副屏与基本中文输入已有真机记录；新版键盘直接输入、手动横／竖屏、Wi-Fi、音频和长时间稳定性仍需分别验收，不能仅凭安装成功判断可用。

详细的两个方向、两种 Wi-Fi 连接、中文输入、扩展副屏和停止行为，见 [用户指南](USER_GUIDE.md)。Mac 应用也内置这份指南，可以离线阅读。
